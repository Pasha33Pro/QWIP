# 🤖 Локальный AI-ассистент с управлением роботизированной клешнёй

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)

![Embedded](https://img.shields.io/badge/Hardware-ESP32-00979D?logo=arduino)
![Status](https://img.shields.io/badge/Status-Active_Development-yellow)

Интеллектуальная система локального искусственного интеллекта, способная видеть окружающую обстановку, понимать
голосовые команды, анализировать ситуацию и управлять роботизированной 4-DOF клешнёй через WiFi. Все вычисления
происходят **локально** на ПК, обеспечивая полную приватность и независимость от интернета.

## 🔧 Технические компоненты

### 1. 🧠 Мозг системы (LLM)

- **Компонент:** `llama.cpp` (llama-server)
- **Модель:** `DeepSeek-V4-Pro-Qwen3.5-9B-UNCENSORED-heretic-i1-GGUF:Q4_K_M`
- **Параметры запуска:**
  `.\llama-server.exe -hf mradermacher/DeepSeek-V4-Pro-Qwen3.5-9B-UNCENSORED-heretic-i1-GGUF:Q4_K_M -c 16384 -fa on -ctk q8_0 -ctv q8_0 --jinja --no-mmproj --port 8080 --host 0.0.0.0 -ngl 99`
- **Роль:** Анализ контекста от камеры и голоса, генерация ответов и команд для робота.
- **Потребление VRAM:** ~6-8 ГБ.

### 2. 👁 Система зрения

- **Компонент:** `YOLOv8` (Ultralytics)
- **Модель:** `yolov8n.pt` (Nano)
- **Роль:** Детекция объектов в реальном времени (~100 FPS на RTX 5060).
- **Потребление VRAM:** ~0.5 ГБ.

### 3. 👂 Распознавание речи (STT)

- **Компонент:** `faster-whisper`
- **Модель:** `base.ru`
- **Роль:** Преобразование голосовых команд в текст (точность ~95% для русского языка).

### 4. 🗣 Синтез речи (TTS)

- **Компонент:** `Edge-TTS`
- **Голос:** `ru-RU-SvetlanaNeural`
- **Роль:** Высококачественная озвучка ответов AI-ассистента.

### 5. 🤖 Контроллер робота

- **Компонент:** `ESP32` (Arduino/PlatformIO)
- **Протокол:** HTTP REST API (POST запросы)
- **Команды:** `grab`, `release`, `up`, `down`, `left`, `right`, `home`.

### 6. 🎼 Оркестратор

- **Язык:** Python 3.10+
- **Библиотеки:** `requests`, `opencv-python`, `ultralytics`, `faster-whisper`, `edge-tts`, `asyncio`.
- **Роль:** Координация всех компонентов, управление потоком данных и парсинг ответов LLM.

## 🚀 Сценарий использования

1. **Пользователь:** *"Возьми красную чашку со стола"*
2. **Система:**
    - Whisper преобразует речь в текст.
    - YOLO анализирует кадр: `"В кадре: red cup, table, hand"`.
    - LLM получает контекст и генерирует: *"Вижу красную чашку на столе. Приближаюсь и захватываю. [CMD: grab]"*
    - Оркестратор парсит `[CMD: grab]` и отправляет HTTP POST на ESP32.
    - Edge-TTS озвучивает ответ, а клешня выполняет действие.

## 🛠 Установка и запуск

1. **Установка llama.cpp:**
   `winget install ggml.llamacpp`

2. **Запуск LLM сервера:**
   Перейти в папку установки и выполнить команду запуска (см. раздел "Мозг системы").

3. **Установка Python зависимостей:**
   `pip install requests opencv-python ultralytics faster-whisper edge-tts`

4. **Прошивка ESP32:**
   Загрузить скетч веб-сервера из папки `/esp32_firmware` репозитория.

5. **Запуск оркестратора:**
   `python main.py`

## 🔒 Приватность и безопасность

- **Локальная обработка:** Голос, видео и диалоги не покидают ПК.
- **Офлайн LLM:** Нет телеметрии или отправки запросов в облачные API.
- **Изолированная сеть:** Управление роботом происходит только через локальный WiFi.
